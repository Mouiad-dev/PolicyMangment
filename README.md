# PolicyDesk

Car and home insurance app for Malaysia (MYR). Learning project:
SQLAlchemy 2.0 async + FastAPI. Built one small step at a time.

## Develop

```bash
just install   # install all dependencies (needs uv)
just check     # ruff lint + format check + mypy strict
just test      # run the tests
```

Needs: Python 3.13, [uv](https://docs.astral.sh/uv/), and
[just](https://github.com/casey/just).
